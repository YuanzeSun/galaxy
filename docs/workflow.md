# 从原片到成片

这份说明描述完整处理顺序。表中的“代码”指本仓库已提供的部分；未封装的步骤需要调用者接入，不会自动完成。

具体怎么连接这些步骤，见[按步骤连接工具和脚本](manual-run.md)。其中有FITS/WCS入口、测光表、照度拟合、面积换算、配准、叠加和后期导出的调用代码，不需要一键程序。

| 步骤 | 输入 → 输出 | 代码或接入要求 |
| --- | --- | --- |
| 保护原片 | 原文件 → 校验清单及独立备份 | `provenance` 生成和检查清单；备份由文件工具完成后核对 |
| RAW 校准 | 匹配的亮场、暗场、相机元数据 → 线性相机数据 | `calibration`；RAW 解码器另行接入 |
| 建立几何 | 星点与星表 → 镜头模型、逐帧变换及留出误差 | 需自行拟合/定位；`geometry` 负责已知模型的计算 |
| 估计照度和曝光变化 | 不饱和恒星测光 → 低频相对响应和曝光偏移 | `photometry`、`selfcal`；测光筛选与留出划分由调用者提供 |
| 对齐与单位换算 | 线性帧、响应、几何 → 同一坐标与单位的图像 | `geometry`、`resampling` |
| 匹配背景并叠加 | 对齐帧及有效覆盖 → 线性母版、覆盖数、拒绝记录 | `background`、`stacking`；批处理调度另行接入 |
| 流星合成 | 确认的单帧轨迹与近邻背景 → 实测流星层 | 方法见下文；没有自动筛选或合成命令 |
| 显示、颜色、标注和导出 | 线性母版 → 成片与来源记录 | 由自己的显示/导出程序接入 |

## 1. 先保护输入

原片目录只用于读取。开始前保存文件清单，复制到独立位置，再对备份逐文件核对。处理结果、参数、临时文件都放在别处。完成后再次核对原片。

`manifest` 只读文件字节，不解码图片。它保存相对路径、大小、修改时间和 SHA256；`verify` 检查完整文件集合。不要把清单存在原片目录内部，否则清单本身会改变待核对的文件集合。

## 2. 校准 RAW

选择曝光、ISO、读出模式和温度条件尽量匹配的暗场。暗场包含偏置时，浮点校准为：

```text
signal = (raw - dark_with_bias) / relative_response
```

统计处理中保留零值和负值。它们是带噪声测量的一部分，不代表“没有拍到”。有效性应由独立掩膜给出。

如果 RAW 解码器必须接收 unsigned CFA，才使用：

```text
decoder_input = round_to_even(clip(raw - dark + black, 0, white))
```

黑电平可能依 CFA 通道或位置变化，不能照搬另一个相机的常数。整数桥不会恢复已经饱和的像素，也不能消除解码器内部的裁剪和量化。本仓库没有把某台相机的高光缩放经验写成通用 RAW 适配器。

## 3. 定位、几何与像素面积

Astrometry 用于确定星点对应的天区，以及不同帧之间如何对齐。镜头模型描述像素与天空方向的对应关系；逐帧变换可在适用条件下用三维旋转表示。

拟合镜头模型和逐帧变换时，留出一部分恒星验证，记录中位及尾部位置误差。高阶模型只有在留出结果稳定改善时才采用。

像素立体角是一个像素对应的天空面积。恒星孔径光量、单位天空面积的表面亮度和参考像素计数不是同一个量。先明确输入单位，再决定如何组合照度响应、立体角和重采样 Jacobian，避免把面积效应除两次。`geometry.solid_angle` 从像素到切平面的模型计算立体角。

## 4. 恒星照度自标定

对同一颗星在不同传感器位置上的孔径测光，拟合低频响应，同时分离恒星本身光量和整次曝光的变化。详见 [flat-field.md](flat-field.md)。

新素材要重新测量和检查，不能直接使用别次拍摄的响应系数、透明度、黑电平或天体保护区。只绕光轴旋转、恒星没有改变半径时，径向响应可能根本无法确定；模型能返回一个数值解并不代表它有物理意义。

## 5. 对齐、背景匹配与叠加

在一致的线性单位下应用响应校正，映射到固定参考画幅。保留真实边界支撑和有效掩膜，没有覆盖的位置保持为空。不要用反射边界或填黑来冒充新观测。

曝光间背景匹配只处理各曝光的相对加性差异。例如，把逐帧平面约束为曝光平均系数为零，避免任意改变共同背景。这里的 `fit_background_plane` 只是单个平面的拟合工具，没有自动完成多帧联合背景求解。

叠加可以使用独立估计的方差权重，或按各组实际曝光数合并。`combine_group_means` 默认不剔除；显式开启时才使用历史的联合通道 MAD 规则。该规则在少数组数下有效率损失，不能默认当作所有数据的最佳选择。

重采样后的相邻像素共享输入，噪声存在相关性。不能只把单像素方差相加，就宣称获得可靠的孔径误差；应再用独立曝光组差值中的空孔径检查。

## 6. 流星、显示与颜色

把已经确认的流星从纯星空底图的对应来源帧中排除。使用其真实单帧减去近邻非流星曝光估计的背景，在轨迹外拟合剩余背景差异，再把带符号的轨迹残差加回对齐底图。不要只保留正残差，否则会产生偏差。跨时刻合成需要明确说明，不能称为同一次曝光。

科学线性母版与显示图分开保存。显示背景是加性估计，照度校正是乘性处理，两者不混为一谈。背景保护、显示拉伸和颜色转换应各有固定参数和检查记录。

用恒星光谱检查颜色时，预先规定饱和、信噪比、孔径一致性和空间覆盖条件。新颜色增益必须通过独立留出检查才应用；不能只看训练星更接近参考色。恒星校色也不自动保证发射星云的颜色准确。

## 7. 导出

最终内容可以分成纯星空、真实流星合成、目录标注三类。标注应直接合成到16位底图，避免 JPEG 中转；文字和引线不要遮住目标。

PNG/TIFF 需要解码回读确认位深、尺寸、色彩配置及像素一致。RGB16 PNG 不能通过普通8位 RGB 接口保存。分享用 JPEG 是单独的有损副本，记录质量、色度采样和大小上限。

保存输入清单、参数版本、输出 SHA256 和采用决定。候选与最终文件分开；发布失败要保留当前结果。这些导出和发布步骤是工作流要求，目前未提供自动执行器。
