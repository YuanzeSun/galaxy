# 怎样判断一个改动值得采用

先固定验证方法，再看候选结果。目标不只是让某个区域变平，还要检查有没有损失真实信号。

## 软件正确性

测试使用已知答案的输入，包括：

- 整数转换误差及半整数取偶，校准后负值保留。
- 多项式坐标映射与解析导数，三维旋转和立体角。
- 重采样对常量、平面、无效边界和方差的处理。
- 有足够运动时恢复合成照度响应；退化或不连通时拒绝拟合。
- 不等曝光数、零值、负值和空覆盖下的叠加。
- 保护区信号改变后，拟合样本和背景预测不变。
- 文件变化、增加、缺失和输出覆盖的检查。

运行：

```bash
python -m unittest discover -s tests -v
galaxy-astro demo
```

## 独立预测

相邻像素不是独立样本。`spatial_folds` 把相邻采样格放到同一块，整块留出。调用者必须只在训练块拟合，再保存留出预测；该函数不会替你训练模型。

检查残差的空间结构时，先按块平均带符号残差，再计算平方误差，避免只用逐像素噪声掩盖低频偏差。`block_mean_residuals` 提供这一步。

`bootstrap_mean` 重抽整个块，保留块内样本和不等块大小，随机种子由调用者记录。`one_standard_error_choice` 在最优留出分数的一倍标准误差范围内选较简单模型。每折是否退化、保护条件和视觉检查仍需单独通过。

同一批数据上的留出和重采样，不能冒充另一台相机、另一晚或另一片天空上的泛化证明。已经反复看过的样本只能用于回归检查。

## 天体保护

保护区应由天体位置、范围或预先定义的天区规则确定，而非看哪里残差不好再圈哪里。`sample_background_cells` 遇到任一保护像素就排除整格；若拟合器使用数据上界，保护区也不得提供这些上界。

检查弥散信号时，向受保护区域注入已知信号后**重新拟合**，再测保留率。固定背景不动的简单加法测试不足以验证拟合过程。即便注入保留良好，也可能把原来已有的暗云压黑，所以还需要：

- 全图及天体区域的近黑比例变化。
- 固定验证星的孔径光量及原先可靠的各颜色通道。
- 全图、边缘和原尺寸区域的视觉检查。
- 新暗带、接缝和边缘发亮检查。

本仓库的平面与保护样本测试检查实现性质，没有宣称能够自动保证任意真实图像的信号保留率。

## 停止条件

候选只放在独立目录。任何预先规定的保护条件失败，就不替换当前结果。不要在失败后放宽门槛、针对用户圈出的区域局部压暗，或继续增加复杂度直到表面指标通过。失败记录也属于方法成果。
