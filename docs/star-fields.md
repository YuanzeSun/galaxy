# 微单＋广角镜头，不同星野怎么处理

这套工具主要处理微单搭配广角镜头拍摄的星空部分。是否包含银河不决定处理流程；关键是星点是否可测、帧间是否有足够位置变化，以及哪些区域包含要保留的真实天体。

RAW校准、几何、像素面积和叠加使用同样的数据接口。天体保护区由本次图像提供，不内置银河方向、银纬范围、固定星云名单或某颗星的位置。

## 按画面选择步骤

| 画面 | 测光与照度 | 背景处理 |
| --- | --- | --- |
| 普通或较稀疏的星野 | 用同一目录连接各帧中可可靠测量的星；按实际位置变化检查能否拟合响应 | 保护亮星、星团、星系及已知弥散结构；天空看着较空也不代表背景为零 |
| 星团或较拥挤的区域 | 挑独立、未饱和的星；检查孔径和背景环带是否混入邻星，不照搬稀疏星野的孔径 | 星团范围及外围光晕进入保护区，不把它们拟合成天空渐变 |
| 星云、反射云或暗云较多 | 仍用合适的恒星测响应；检查局部背景是否影响测光 | 发射、反射和暗云都可能很弥散；不因为离银河远或颜色偏暗就当作空白背景 |
| 银河区域 | 使用未饱和且不过度混叠的恒星；响应仍按该批光学状态估计 | 按实际银河、星云和暗云范围保护；历史案例的银纬掩膜不是默认规则 |
| 带地景、树木、山脊或云的星空 | 测光和叠加掩膜先排除这些区域及遮挡帧 | 本仓库处理星空部分；地景需要另行对齐/合成，不随星点配准一起平均 |

可以对照[孔径测光说明](https://siril.readthedocs.io/en/stable/photometry/quickphotometry.html)设置孔径及环带。背景取样应排除真实天体，相关原则见[Siril背景提取说明](https://siril.readthedocs.io/en/stable/processing/background.html)。这些外部资料是方法参考，不代表其软件功能已经都移植到本包。

## 有星不等于照度一定能自标定

星的数量、分布、帧间移动和观测连接共同决定信息量。不能按“是否银河”判断，也不规定任意一个最低星数就算可靠。

- 固定三脚架时，检查星是否经过不同传感器位置和半径，不能只看天区明显转动。
- 使用跟踪器时，星可能长时间留在同一位置；这对叠加有利，却可能无法从这些帧估计位置响应。
- 稀疏星野中，少量恒星也可能在数学上给出满秩模型，但精度、位置覆盖和留出结果仍可能不足。
- 缺少有效位置变化、观测不连通、条件数很差或留出结果不稳定时，不强行生成照度系数。可以使用与本次光学状态匹配的实拍平场，或跳过未验证的乘性校正，保留线性母版和已知不均匀。

`response_information`检查必要的信息条件；`fit_stellar_response`拒绝秩不足或不连通的输入。通过这两项仍需数据验证，不能把结果称为真实二维平场。

## 没有可靠空背景时

`sample_background_cells(image, protected, ...)`接受任意位置、形状的保护区。某格有一个保护像素就排除整格；没有“画幅中央是银河”之类的假设。

微弱星云或暗云可能铺满画面。此时不用强求最终背景扣除：

1. 保留未做显示背景扣除的线性母版。
2. 只做能通过验证的曝光间相对匹配；差值中的天体残差也要排除。
3. 无足够样本或无法保护真实结构时，跳过该候选，保留背景渐变。不要缩小保护区来凑样本。

代码会拒绝没有样本或平面秩不足的输入；样本“是否真是天空”仍由使用者检查。自动掩膜和自动判断整幅弥散结构目前没有实现。

## 广角镜头需要注意什么

- 边缘畸变、星像和像素天空面积可能与中央不同，用完整画幅的星点核验WCS或相机模型。
- 跨经纬、接近天极或有SIP畸变的WCS都通过同一坐标接口连接，不使用原项目的中心天区。
- 不同光圈、焦距、对焦、滤镜及有效画幅应分别记录，照度响应不能只凭“同一镜头”就混用。
- 鱼眼、接近180°或投影非常特殊的画面需要合适的求解和投影模型，不能默认用普通切平面模型外推整幅图；本项目当前优先面向普通广角星野。

具体调用顺序仍见[按步骤操作](manual-run.md)。流星合成、目录标注、最终背景处理都是可选分支，没有这些需求可以直接略过。
