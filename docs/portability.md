# 换相机、参数或天区时

仓库的数值函数接收数组、坐标和参数，不读取某个品牌的RAW，也没有内置本次拍摄的尺寸、黑电平、镜头系数或天区。不同设备通过适配器交出相同约定的数据后，可以使用同一套数值步骤。

下面区分“方法可复用”和“旧数值可沿用”：

| 内容 | 换一批数据时怎么处理 |
| --- | --- |
| 减暗场、最近整数、坐标映射、重采样、叠加的计算方法 | 共用代码 |
| 机身RAW格式、CFA排列、黑/白电平、有效画幅、通道缩放 | 从本批元数据和解码器取得；不使用旧常数 |
| 白平衡及相机颜色配置 | 明确选择并记录；固定解码约定，避免漏做或重复做颜色转换 |
| 镜头模型 | 同一光学状态可以作初值，仍用新星点验证；也可以直接使用各帧WCS |
| 恒星估计的照度响应 | 用本批测光重拟合，并用留出星验证。换光圈、焦距、对焦等光学条件时分组处理 |
| 各帧曝光偏移、对齐映射、背景及覆盖 | 重新计算 |
| 孔径、SNR条件、误差底限、分组、剔除尺度 | 按新数据事先设置并验证；示例数字不是通用推荐值 |
| 天体保护区 | 按新天区生成；没有强制使用固定银河掩膜 |

具体连接方式见[按步骤操作](manual-run.md)。其中WCS路线不要求复用原项目的多项式镜头模型；坐标由每张图的求解结果提供。已有相机模型时，也可以接`geometry`的计算函数。

## 适用条件

- 示例读取二维单通道或三通道RGB线性FITS。原始CFA、光谱数据立方或其他文件布局需要自己的适配器。
- 数据单位、坐标方向和已经做过的校正必须明确。不能把显示图当线性图，也不能再次扣已扣过的暗场或再次除已校正的平场。
- 默认照度示例使用固定中心的径向模型，并把G通道估计的响应共同应用到RGB。这些是模型假设，需要逐批检查，不保证描述任意镜头、灰尘或颜色依赖。
- 星与曝光之间必须有足够连接和位置变化。信息不足时拒绝拟合，不借用本项目的系数填补。
- WCS需要在完整图幅内有效。明显位置误差、坏天区解或不能收敛的反变换不能靠后续插值补救。
- 实际天体保护、噪声、共享校准误差和颜色准确性仍需数据验证。

## 目前怎样检查通用性

软件测试覆盖不同数组尺寸、像素尺度、旋转、高赤纬和赤经跨零点，检查WCS正反方向、SIP镜头畸变、单通道/RGB、实际覆盖、负值与空值，以及照度模型退化时的拒绝行为。数值公式还与已知解析答案比较。

`connect_steps.py`中的尺寸、坐标、星点、响应和曝光变化全部是合成数据，只为展示接口。测试在Windows/Linux及Python 3.11/3.13运行；这些测试证明实现中的具体性质，不代表已用所有机型的真实照片验证。
