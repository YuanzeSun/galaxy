# 一次处理留下的取舍

这份记录来自一次广角银河拍摄：381张亮场、10张暗场。这里只记录方法结论，不附原片、成片、星表、缓存或拟合参数。

## 留在实际流程里的改动

- 原片与备份逐文件校验。
- 暗场校准后的整数接口改为最近整数、半整数取偶，去掉直接截断的单向偏差。这不等于所有像素噪声都降低。
- 用物理镜头模型和逐帧天空旋转约束配准，分别记录几何与光量单位。
- 利用恒星测光估计低频相对响应和曝光变化，保留可辨识性限制。
- 用实际覆盖数叠加；科学线性母版与显示处理分开。
- 流星使用实际曝光的带符号残差合成，并明确属于跨时刻合成。
- 标注直接作用于16位底图，格式转换后回读核对。

## 没有采用的尝试

| 尝试 | 没有采用的原因 |
| --- | --- |
| 均值/截尾暗场替换及整体暗场缩放 | 暗场内部预测略有改善，不能直接证明对亮场适用；温度和样本条件不足 |
| 更复杂的逐曝光稳健估计与原生星像模型 | 真实数据的预测尾部或相关误差检查未通过 |
| 重新拟合全局颜色增益 | 留出星色误差总体变差，沿用原有白平衡和颜色矩阵 |
| 下方亮带的全局保护样条修正 | 亮带指标改善，但银河暗云新增压黑，保护条件失败 |

## 亮带为什么停止修正

亮带相关的不均匀在单帧中已有迹象，不能只归因于叠加。另一批不同指向和曝光设置的素材没有持续重现同样的正向残差，更支持随方向或时间变化的背景因素；但比较中使用了既有固定照度模型，不能当成独立实拍平场证据，也没有唯一分清光害、气辉、薄云散射或杂散光。

最后一轮固定比较了三个全局样条尺度。独立选出的候选把同定义亮带指标从约1.02降到0.069，但全图近黑比例增加约0.386个百分点，超过预设0.1个百分点上限；原尺寸检查也看到上方银河暗云压黑。三个候选均没有替换最佳结果。

后来决定接受残余亮带，停止这条修正路线。发布到仓库的是工作流、基础方法与失败教训，不包含这套被否决的修图算法，也没有继续运行实验。
