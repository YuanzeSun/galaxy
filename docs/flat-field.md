# 恒星照度自标定与真实平场

实拍平场是让传感器接收尽量均匀的照明，用来测量位置响应。没有这类照片时，可以利用恒星在传感器上的移动，估计部分低频响应。

仓库采用的数值模型是：

```text
log(measured_flux[i]) = features[i] @ theta
                     + star_log_flux[star[i]]
                     + exposure_log_offset[frame[i]]
```

`features` 由调用者构造。例如 `radial_features` 产生 r²、r⁴ 列，中心和归一化尺度均由调用者提供。响应为 `exp(features @ theta)`。第一个排序曝光的偏移固定为零，用来确定数值基准。

`fit_stellar_response` 用稳健加权最小二乘拟合。它先从响应特征中去掉恒星和曝光偏移能够解释的部分，再求响应系数。返回系数、恒星/曝光偏移、预测、残差和必要的可辨识性检查。输入误差是 log-flux 的标准差，不是原始计数的标准差；低信噪比测量不能直接套用近似误差传播。

## 什么情况下解不出来

- 同一颗星始终位于同一位置：位置响应可以被每颗星自己的光量吸收。
- 纯绕光轴旋转、半径不变：径向响应可能没有足够信息。
- 所有恒星随曝光共同变化的特征：可能被曝光偏移吸收。
- 恒星与曝光观测图不连通：不同分组之间没有共同光量基准。

`response_information` 检查去掉这些偏移后，特征是否还有足够数值秩，并报告奇异值和条件数。`fit_stellar_response` 拒绝秩不足或观测图不连通的输入。

数值秩通过只说明“在这个模型里有机会区分参数”。大气消光、孔径漏光、星像变化、颜色依赖和错误的模型族仍可能污染结果。接近退化的特征也可能虽然满秩，却精度很差。

## 采用前要检查什么

1. 选择未饱和、测光稳定的恒星，保留剔除原因。
2. 固定响应模型族和候选复杂度。
3. 留出恒星、时段或区域，检查它们上的光量稳定性，而非只看训练残差。
4. 检查外推范围；观测没覆盖的位置不能凭高阶模型宣称校准完成。
5. 同时检查最终恒星光量、星像和弥散结构。

测试中的合成数据知道真实响应，所以能检查求解器。真实天空没有提供这个答案，不能把软件测试通过等同于恢复了真实平场。

## 保留的限制

径向低频模型不完整描述灰尘斑、任意二维响应或每个颜色通道的差异。背景梯度也不能直接用作镜头响应：真实银河和加性前景会混在其中。

像素立体角、镜头响应和大气透过率分别记录。用恒星点源测得的响应如何转换为弥散表面亮度，需要明确面积与单位定义，不能统一叫作“平场”后反复相除。
